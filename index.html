F被動 = q × S × C下壓

F總下壓 = F車身 + F尾翼 + F風扇

下壓力增加抓地上限，但不等於推進力。低速可在輪胎受限時幫助加速；高速受功率限制時，風扇耗電、滾阻與尾翼阻力也會帶來代價。風扇耗電已從本模型的驅動功率預算扣除。

TRY / 01

車速設為 0

車身與尾翼的被動空力歸零。只要風扇開啟且有密封壓差，車底仍有吸力與抽氣流動。

TRY / 02

固定「密封」，把車速加倍

同角度、同模式下，被動下壓力與風阻依 v² 增為四倍。固定風扇轉速時，抽吸部分由壓力—流量曲線決定。

TRY / 03

開啟冷氣體推進器

四個後噴口以獨立白煙呈現，與彩色氣流分開。假設噴嘴水平排氣，因此增加前進推力、不直接增加下壓力。白煙濃淡、擴散與播放速度僅為視覺示意，不能據此判斷推力或氣體濃度；未求解凝結、可壓縮流或震波。

外觀比對：使用者提供的錄影在「High-Downforce Mode」呈現前輪後方側板向外展開。本頁新增收合／展開示意，位置依畫面重建，尺寸、鉸鏈與展開幅度為估計；尚未求解導板局部流場或受力，也不將它當作加速噴嘴。車門內收不等於輪胎突出於輪拱，輪距與車寬仍待尺寸資料校準。

粒子怎麼算？哪些地方是近似？

車身繞流使用預設的平滑路徑與「流管截面」近似；依 Q = uA 算局部速度，再按 ds/dt = u 推進粒子，顏色使用同一速度。風扇路徑則由模型抽氣流量與假設通道截面決定速度。彩色粒子以 0.08 倍慢動作呈現，播放倍率只改變觀看速度。粒子數量是觀看設定，疏密不代表空氣密度或壓力；白煙使用獨立的視覺動畫，不套用速度色階。

每條流管的流量在此近似中守恆，但它們不是完整、連續的三維 CFD 解。路徑、流管截面、尾流擴散與風扇位置均為示意；未計算邊界層、渦流、湍流、風扇旋轉流場及噴嘴可壓縮流。下壓力由下方集總公式估算，並非把粒子流場的表面壓力積分而得。綠色光區表示平均低壓，並非壓力分布量測。
